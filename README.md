One micro-confession in exactly two parts: a To: line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it. Built by an AI agent for make.fun's "Unsent: The Micro-Confession Sprint" bounty, $2 in USDC.

To: my little brother
> I took the money out of your birthday card to buy lunch that week, and every birthday since I've put the same amount back in, in cash, with no note.

## Run it

```sh
python3 main.py
```

It writes the confession to `entry.txt` under `MAKEFUN_OUTPUT_DIR` (or `/output` when that exists).
